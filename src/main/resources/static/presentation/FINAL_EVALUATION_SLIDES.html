CUSoC Final Evaluation · October 26, 2026

TruthLens (S-09)

Online Misinformation Awareness Campaign for Young Adults

Verify before you amplify · SIFT literacy · measurable campus impact

1. The Problem

  • Health myths, phishing, and deepfakes spread via WhatsApp & Reels
  • Young adults (18–25) amplify claims before verifying
  • Need: skills + tools + measurable behavior change

2. Our Solution

  • Interactive SIFT claim analyzer
  • Digital literacy modules & resource guide
  • Baseline / endline susceptibility surveys
  • Workshops + peer multiplier training
  • Live impact analytics dashboard

3. Tech Stack

  • Java 17 · Spring Boot 3.4 · Spring Security + JWT
  • JPA · H2 (local) / PostgreSQL (cloud)
  • OpenAPI / Swagger
  • Responsive campaign website (Tailwind SPA)

Repo: modular controllers · services · repositories · automated tests

4. Live Demo Flow

  1. SIFT Analyzer → sample health myth → FALSE + steps
  2. Susceptibility quiz → score persisted
  3. Workshop registration
  4. Analytics KPIs refresh
  5. Swagger + documentation links

App URL: http://localhost:8080
